## 0. 先看懂三条规则（30 秒）

**规则 1：模组分"服务器装"和"客户端装"，不是一回事。**
- `client_only_mod = false` → **服务器必须装**（本文档重点讲的 31 个）。
- `client_only_mod = true` → 纯客户端模组，服务器装了也没用（本文档第 4 节的 23 个）。
- `all_clients_require_mod = true` → **所有玩家必须订阅同一个模组**，否则进不去服务器、或进去后物品显示异常。

**规则 2：服务器不进你的 Steam 账号，模组是匿名下载的。**
服务器用 steamcmd 匿名把工坊内容下到 `mods/workshop-<ID>`，再由 `modoverrides.lua` 决定开不开、参数怎么配。所以同一个订阅列表，你可以"只装一部分"。

**规则 3：装/换模组 = 服务器重启 + 世界重载。**
重启时自动备份存档；**大改类模组（UM、登仙、樱花林等）有概率让旧存档出问题**，所以大模组建议在"开新世界"前装好。

> **关键概念：客户端必装 ≠ 服务器必装。** 比如小地图（Minimap HUD）是全客户端模组，你朋友订阅就行，服务器完全不用装；而 Global Positions 这种"服务器要算、客户端要显示"的，两边都得装。

## 2. 逐个说明

### A 组 · 工具与信息类

#### 1) Global Positions — `378160973` · 0.6 MB · 2026-04-20
**功能**
- 地图 / 小地图上实时显示所有玩家的位置，鼠标悬停可看是谁。
- 玩家离得远时，屏幕边缘出现指示气泡（对应角色头像）。
- 信号火（signal fire）会在小地图上显示为指示点。
- **Alt + 点击地图**可在世界地图上打 Ping 标记，队友都看得到；静音某个玩家会隐藏他的 Ping。
- 手柄玩家：点右摇杆 Ping。

**装到专服**：轻量，几乎零负担。建议搭配 Minimap HUD（客户端模组）一起用，小地图才能看到位置。

---

#### 2) Show Me (Origin) — `666155465` · 0.2 MB · 2022-01-08
**功能**
- 鼠标**悬停**物品即显示信息（食物属性、武器伤害、护甲减伤等），不用捡起来看。
- 只在鼠标指向物品时才走网络，流量很省。
- 作者建议与 Health Info（血量显示）搭配；检测到 Health Info 时自己不显示血量以免重复。

**注意**：与 Show Me (New)、Insight **三选一**（功能重叠，同时开会出现信息重复甚至遮挡）。

---

#### 3) Show Me (New) — `2287303119` · 0.4 MB · 2026-10-27
**功能**
- 在 Show Me (Origin) v0.58 基础上由社区维护的更新版（GitHub: BB-GOAT/show_me）。
- 适配新版本游戏内容，修复 Origin 版停更后的问题。

**注意**：同上面——三选一。

---

#### 4) Insight (Show Me+) — `2189004162` · 31.9 MB · 2026-09-14
**功能**
- 悬停显示物品/生物信息，**从零重写**，比 Show Me 更准（作者原话：Show Me 对某些东西的描述不准确）。
- 对视野内物品做**区域缓存**，来回扫鼠标不重复请求，性能好。
- 100 万订阅，维护活跃。

**推荐**：三兄弟里选它，信息最全、最准。体积 31.9 MB 对服务器无感（主要是客户端资源）。

#### 5) [TMIP] Too Many Items Plus — `1365141672` · 5.2 MB · 2022-07-29
**功能**
- **仅管理员可用**：按 `T` 打开刷物品菜单，左键刷 1 个、右键刷 10 个。
- 可自定义收藏清单（Ctrl + 点击 增删）。
- 用于建家、测试、补 bug 掉的物品。

**注意**：作者已停止维护（2021-12-10 起），新版游戏偶有 UI 错位。适合自己玩/建房，作为常驻模组意义不大 → **建议不装**，需要时再开。

#### 6) Storeroom (New) — `2784048339` · 1.1 MB · 2026-07-31
**功能**
- **SortOut 整理**：一键把箱子内容排序。
- **容器拖拽**：Alt + 右键拖箱子，把容器搬到另一个容器里。
- 减号键重置排序。
- 可设置**保鲜天数上限**（冰箱不再无限保鲜）。
- 防熊孩子：可设"仅自己可破坏"，熊獾/其他生物也拍不出物品。
- 兼容 `chestupgrade_stacksize` 类升级箱（升级后不执行整理功能）。

**装到专服**：轻量、强烈推荐，多人开荒必备。

**功能**

- 带储物能力的装备（背包类）也能正常用。

**注意**：与 999 Stack Size、Infinite Stacks 都改堆叠 → **三选一或最多留两个**。

#### 14) Infinite Stacks — `3206595446` · 0.4 MB · 2026-02-26

## 5. 三套推荐组合（直接挑一套）

### 组合 A｜轻量工具流（推荐先用这一套）
**服务器装 9 个，约 35 MB；朋友订阅 9 个。**

| 类别 | 模组 |
|---|---|
| 信息 | Insight (2189004162)、Global Positions (378160973) |
| 效率 | Storeroom (2784048339)、Extra Equip Slots+3 (2798599672)、Fast Travel (1530801499) |
| 堆叠 | Lag Remover (3050607025)、999 Stack Size (831523966) |
| 表现 | More Emotes (2623277832)、Epic Healthbar (1185229307) |

- 纯提效，不改游戏机制，**旧存档也能直接加**。

- 实测负担：服务器内存约 +200–400 MB，启动时间 +10 秒左右（体量小，风险低）。

### 组合 B｜内容扩展（神话线）
**组合 A + 神话套装 + 勋章，约 470 MB。**

再加：神话书说 (1991746508)、神话人物 (1699194522)、腌笃鲜 (3625940357)、能力勋章 (1909182187)、坐着轮椅玩勋章2 (3786404160)。
- 朋友订阅：A 组全部 + 上面 5 个（合计 14 个）。
- **新开世界时用**，旧存档不建议中途加。
- 4 GB 内存机器：建议先 `swap` 已开（2 GB，已配好），加载后再看内存曲线。

### 组合 C｜大杂烩（不推荐直接上）
31 个全装 ≈ **1.91 GB**，启动慢、内存爆、冲突多（UM × 登仙 × 樱花林 × 军团 同开风险最高）。

2. 一次加 2–3 个，观察一轮日志再继续；

## 6. 选定之后怎么装（我来执行）

你只要回我一句，比如"装 A 组合"或"装这几个 ID：...",我在服务器上执行：

```bash
# 添加（单个 mod 或合集）
dst-mods add 378160973
dst-mods add 2189004162

# 查看清单 / 检查更新 / 看状态
dst-mods list
dst-mods check
dst-mods status

# 一键更新全部（会自动：重写 setup → 下载 → 同步 → 写 modoverrides → 备份 → 重启）
dst-mods update
```

**`update` 会自动做的事**（已在这台服务器上验证过）：
1. 重写 `mods/dedicated_server_mods_setup.lua`（防止游戏更新把它重置掉）；
2. steamcmd 匿名下载到 `steamapps/workshop/content/322330/<ID>`，再同步到 `mods/workshop-<ID>`；
3. 生成 `Master/modoverrides.lua`（保留你已配好的参数）；
4. 备份存档 → 重启 → 轮询日志直到 `Online Server Started` / `Sim paused`；
5. **有人在线时会拒绝重启**（除非加 `--force`）。
