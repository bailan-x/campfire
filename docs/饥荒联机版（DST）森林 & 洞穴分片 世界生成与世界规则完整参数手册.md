# 饥荒联机版（DST）森林 & 洞穴分片 世界生成与世界规则完整参数手册

> 文档格式：Markdown，可直接复制保存为 `.md`
>
> 核心前提：
>
> 饥荒联机采用**分片架构**
>
> 分为两大类别：
>
> 
>
> 1. **世界生成设置（World Generation）**：地图创建阶段一次性运算，**存档生成之后永久锁定，游戏内无法修改**，控制地形、群系、资源点位、巢穴、特殊结构的布局与点位。
> 2. **世界规则设置（World Settings）**：运行时动态规则，**存档开启后，主机随时可以在世界设置面板修改，修改后即时生效**，控制季节、袭击、生物刷新、伤害倍率、再生、死亡复活、事件开关等。

## 一、通用档位与术语定义

### 计数类通用档位（资源、生物、事件、群系数量）

表格







| 档位 |                     释义                     |
| :--: | :------------------------------------------: |
|  无  |           完全不生成、不刷新该对象           |
| 极少 |         极低概率，零星点位，很难遇到         |
|  少  |             数量低于官方原版标准             |
| 默认 |             原版官方预设基准数值             |
|  多  |               数量高于原版标准               |
| 大量 | 高密度，实体数量暴涨，服务器负载高，极易卡顿 |

### 再生速度档位（草木、矿石、植物恢复）

表格







| 档位 |                 释义                 |
| :--: | :----------------------------------: |
| 极慢 |      恢复周期大幅拉长，资源紧缺      |
|  慢  |             恢复周期拉长             |
| 默认 |           原版标准再生速度           |
|  快  |      恢复速度提升，资源供给充足      |
| 极快 | 高速再生，资源泛滥，不适合长期养老档 |

### 倍率类选项

伤害、环境致死为独立三档：降低 35% / 默认 / 提高 35%

## 二、森林分片（地上世界）完整参数

### 2.1 森林 - 世界生成设置（存档生成后永久锁定）

#### 2.1.1 基础地图参数

1. 世界大小：极小 / 小 / 默认 / 大 / 巨大

2. 道路：无 / 小路 / 默认 / 大路（道路为地皮路径，连接各个区块；大路更容易找到跨区域资源）

3. 地图排布模式：

   - 分类（区块式，原版经典）：同类型群系集中成片
   - 圆形（环形）：地图从内向外环形排布

   

4. 起始区域：默认开局 / 补给增强（开局附带额外补给箱） / 黑暗补给（暗无天日预设专属开局，仅提供火把补给）

#### 2.1.2 生物群系配置（控制该群系在地图上占比）

草原、落叶林（常青松林）、桦树林、沼泽、岩石矿区、沙漠、红树林、月岛、墓地、猪王平原

- 草原：草、兔子、牦牛、淡水池塘
- 落叶林：松树、蜘蛛、树人
- 桦树林：桦树、桦果、浣熊猫
- 沼泽：触手、芦苇、鱼人
- 岩石矿区：石头、金矿、高脚鸟
- 沙漠：蚁狮、仙人掌、风滚草
- 红树林：近海、螃蟹、红树林树木
- 月岛：月岩、月系生物、月科技台
- 墓地：坟墓、幽灵
- 猪王平原：猪王、猪人村落

#### 2.1.3 基础资源点位生成（点位固定，生成时一次性刷出）

浆果丛、干草（草根）、树枝丛、松树、桦树、芦苇、石头、金矿、燧石、大理石、鲜花、红 / 绿 / 蓝蘑菇、曼德拉草、淡水池塘

> 备注：池塘点位属于生成项；池塘内的鱼、青蛙属于运行刷新，受世界规则控制

#### 2.1.4 巢穴、定居点、BOSS 点位生成（点位是否存在在此决定）

蜘蛛巢、海象冰屋、高脚鸟巢、野牛群点位、猪人房屋、鱼人房屋、复活台（生命之泉 Touchstone）、猪王、蚁狮祭坛、蜂后蜂巢、克劳斯赃物袋点位

#### 2.1.5 传送通道结构生成

地上虫洞、落水洞（**重点：落水洞入口属于森林分片生成项，不是洞穴分片**）、沉船、海盗营地

#### 2.1.6 特殊生成选项

1. 多汁多枝树苗：无 / 极少 / 少 / 默认 / 多 / 大量；替换普通树苗，产出多汁浆果；大量会生成海量实体，是服务器卡顿高发原因
2. 草壁虎转化：草根被采集后，转化为草壁虎的概率档位

------

### 2.2 森林 - 世界规则设置（运行中主机可随时修改）

#### 2.2.1 死亡、复活与全局惩罚规则（跨分片全局生效，森林主控）

1. 绚丽之门复活：开启 / 关闭；关闭后，仅复活台、强心针、生命护符可以复活玩家
2. 幸存者死亡形态：死亡变鬼魂（队友可救援） / 直接返回选人界面（荒野模式）
3. 鬼魂全队理智流失：开启 = 任意玩家变鬼，全队持续掉 san；关闭 = 仅鬼魂自身损失理智
4. 全员死亡重置倒计时：无（无尽模式） / 5min / 10min / 30min / 60min；全部玩家死亡后倒计时结束，世界重置
5. 生命上限惩罚：开启 = 每次死亡永久扣除最大生命值；关闭 = 无生命上限惩罚
6. 受到伤害倍率：降低 35% / 默认 / 提高 35%
7. 极端环境致死判定（饥饿、低温、高温、黑暗）：默认（可以直接致死） / 非致死（仅扣血，不会直接死亡，轻松模式）
8. 玩家出生点位：绚丽之门出生 / 地图随机出生（荒野模式）

#### 2.2.2 季节、昼夜配置

1. 开局季节：随机 / 秋天 / 冬天 / 春天 / 夏天
2. 四季时长独立设置：秋季、冬季、春季、夏季，档位：无 / 很短 / 短 / 默认 / 长 / 很长
3. 昼夜循环类型：长白天、长黄昏、长黑夜、无白天、无黄昏、无黑夜、永久白天、永久黄昏、永久黑夜（暗无天日预设）

> 备注：昼夜循环仅森林生效，洞穴没有独立昼夜周期

#### 2.2.3 天气与自然灾害事件（地上独有，洞穴无）

降雨频率、闪电雷击频率、野火（夏季植被自燃）、青蛙雨、沙尘季风、月裂隙 & 月蚀事件频率

#### 2.2.4 节日活动控制

节日模式：跟随官方服务器时间 / 永久开启 / 关闭

包含：冬季盛宴、万圣之夜、生肖新年活动

#### 2.2.5 资源再生速率

草、树枝、浆果、树木等基础资源再生速度（极慢 / 慢 / 默认 / 快 / 极快）

#### 2.2.6 袭击事件频率

猎狗袭击（普通猎狗、火狗、冰狗）、海盗袭击

#### 2.2.7 生物与 BOSS 刷新频率

普通生物：蝴蝶、鸟类、萤火虫、秃鹫、蜜蜂、黄蜂、猪人、鱼人、野牛、浣熊猫、考拉象、高脚鸟、发条生物、暗影生物、触手

BOSS：巨鹿、麋鹿鹅、熊獾、龙蝇、蚁狮、蜂后、克劳斯、蜘蛛女王、海象

特殊独立项：坎普斯（小偷）刷新频率

#### 2.2.8 其他补充规则

复活台重置刷新速度（复活台点位是生成项，使用后的重置刷新属于规则项）

## 三、洞穴分片（地下世界：洞穴一层 + 远古遗迹 / 暗影中庭）完整参数

> ⚠️ 前置说明：洞穴分片**没有四季、野火、青蛙雨、沙尘、蚁狮、龙蝇、月岛群系**；光照依靠荧光果、人工光源；落水洞出口由洞穴生成，和森林的落水洞入口一一对应；洞穴不控制死亡复活逻辑，复活规则完全由森林分片接管。

### 3.1 洞穴 - 世界生成设置（存档生成后永久锁定）

#### 3.1.1 基础地图参数

1. 洞穴世界大小：极小 / 小 / 默认 / 大 / 巨大
2. 洞穴道路：无 / 小路 / 默认 / 大路
3. 远古遗迹布局密度：稀疏 / 默认 / 密集；控制远古迷宫、铥矿建筑群分布密度

#### 3.1.2 洞穴生物群系配置

荧光草区、香蕉丛林、兔人平原、洞穴沼泽、岩石洞穴、蜗牛岩区、远古遗迹地皮、暗影中庭地皮

- 荧光草区：荧光果、荧光果虫
- 香蕉丛林：香蕉树、火药猴
- 兔人平原：兔人、胡萝卜
- 洞穴沼泽：洞穴触手
- 蜗牛岩区：蜗牛、石笋
- 远古遗迹：铥矿雕像、远古建筑
- 暗影中庭：远古织影者专属场地

#### 3.1.3 洞穴资源点位生成

荧光果丛、香蕉树、芦苇、苔藓、蕨类、石笋、铥矿、噩梦花、洞穴池塘

#### 3.1.4 洞穴巢穴、建筑、BOSS 点位生成

兔人房、猴子窝（火药猴）、洞穴蜘蛛巢、白蜘蛛巢、蜗牛窝、铥矿雕像、铥矿墙、远古大门、远古宝箱、洞穴复活台

特殊结构点位：远古守卫（犀牛）平台、暗影中庭（织影者场地，点位存在与否在此决定）

#### 3.1.5 洞穴传送通道生成

洞穴虫洞、落水洞向上出口（对应森林分片的落水洞入口）

> 注意：虫洞仅在同分片内传送，**森林虫洞和洞穴虫洞不能跨分片连通**

### 3.2 洞穴 - 世界规则设置（运行时主机可随时修改）

#### 3.2.1 洞穴专属灾害事件

地震频率、蠕虫袭击（地下猎狗突袭）频率、洞穴裂隙刷新频率、远古暗影暴动触发频率

> 地震：掉落碎石、矿石，碎石可以砸伤玩家；大量地震会持续干扰玩家、增加服务器负载

#### 3.2.2 洞穴生物、BOSS 刷新频率

普通生物：蝙蝠、毒蝙蝠、荧光果虫、兔人、石虾、蜗牛、暗影猴（火药猴）、洞穴蜘蛛、白蜘蛛、洞穴触手、凝胶蛞蝓

BOSS：深渊蠕虫、远古守卫（犀牛）、远古织影者、暗影三基佬（暗影棋子）

> 重点提醒：石虾设置【大量】极易泛滥堵路；火药猴大量会持续偷取玩家物品、高频骚扰，AI 计算量大，非常吃服务器性能

#### 3.2.3 洞穴资源再生速率

荧光果、香蕉树、芦苇、苔藓、蕨类、铥矿矿石再生速度（极慢 / 慢 / 默认 / 快 / 极快）

## 四、森林与洞穴分片联动逻辑（高频踩坑点）

1. 落水洞：森林分片生成**入口**，洞穴分片生成**出口**；两边数量尽量匹配，否则会出现有入口无出口或者有出口无入口
2. 复活 / 死亡重置：森林分片主控鬼魂、复活、世界重置全部规则，洞穴无独立设置
3. BOSS 隔离：龙蝇、蚁狮、巨鹿、蜂后、克劳斯、麋鹿鹅、熊獾仅森林；织影者、远古犀牛、暗影三基佬、深渊蠕虫仅洞穴
4. 事件隔离：季节、青蛙雨、野火、沙尘只在森林；地震、蠕虫袭击、暗影暴动只在洞穴
5. 裂隙隔离：森林月裂隙、洞穴裂隙是两套独立事件，互不影响
6. 虫洞隔离：森林虫洞、洞穴虫洞互相独立，无法跨分片传送

## 五、预设机制说明

所有一键预设（标准生存 / 无尽 / 荒野 / 轻松 / 暗无天日）本质是**批量填充森林分片的生成参数 + 规则参数**；洞穴分片默认加载标准洞穴 DST_CAVE 参数。

> 一旦你在预设基础上手动修改任意一项参数，存档就不再是原版预设，参数以你手动修改的值为准。
>
> 泰拉联动分片（TERRARIA / TERRARIA_CAVE）为独立特殊分片，拥有专属生物、群系，不在这份原版参数范围内。

## 六、服务器性能避坑指南（自建专用服务器重点）

1. 【大量】档位会暴涨实体数量，拉高 CPU、内存负载，容易掉 tick、卡顿、崩溃
2. 多汁多枝树 = 大量：是饥荒服务器卡顿头号元凶之一
3. 石虾、火药猴 = 大量：AI 持续运算，性能消耗极高
4. 地震 = 大量：持续生成落石实体，加重服务器压力
5. 巨大地图 + 大量资源 + 大量生物：不推荐低配服务器
6. 长期养老档建议：资源上限设置为【多】，不要拉到大量；袭击、地震推荐【少】或【默认】
