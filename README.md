> 📦 本仓库是作品集快照，已做脱敏：真实 IP / 域名 / 口令 / Klei Token / SSH 私钥全部移除或替换为占位符（见 [仓库说明.md](仓库说明.md)）。代码与文档为 2026-11-03 的版本。

给自建饥荒专服的服主用的管理面板：**跑在自己电脑上**，远程管理云服务器上的游戏服——一键部署、一键开服、创意工坊模组一键更新，服务器常驻自治，电脑关机也不影响朋友联机。

## 方案速览

- **形态**：本地桌面面板（Windows，Go 单二进制 + 系统托盘 + 内嵌 Vue3 UI + SQLite）+ 云服务器 Linux Agent（systemd 常驻）+ SSH 加密隧道；不做小程序、不做移动端
- **为什么这么分**：DST 没有官方 RCON，只能在云服务器侧用 PTY 托管进程；把执行层放 Agent、面板只做编排，才能做到"关电脑服务器照跑"
- **技术**：Go + SQLite + Vue3；Lua ⇄ JSON 配置管线；任务系统带幂等与断线重连
- **三条硬约束**：无 RCON → PTY + stdin marker；工坊无历史版本 → 更新前快照可回滚；`app_update validate` 会重置模组清单 → 每次更新后强制重建
- **云服务器**：阿里云 ECS · Ubuntu 22.04 LTS · SSH 22 端口 + 密钥对 · 通用型 2C4G 起（6–8 人双分片 4C8G），详见 §10.2
- **访问与用户**：v1 面板只监听 `127.0.0.1`（不需要域名/证书/备案），单用户（你自己）；多用户与局域网/公网访问为 P1 预留
- **范围**：先单台云服务器、多存档；UI 与数据模型预留多节点
- **排期**：M0 五个 spike 4–6 天 → M1 MVP 约 4 周 → v1.0 → v2.0；MVP 约 95 人日（单人约 3.5 个月）
